# הקיוסק של 42 🖥️

מערכת ניהול תוכן למסך המשרד: **נגן** שרץ על המסך ומציג פלייליסט של סרטונים, אתרים ותמונות, ו**דף ניהול** שנכנסים אליו מהנייד כדי לשלוט במה שמוצג.

## איך זה בנוי

- **דאטהבייס:** Google Sheets (אפשר גם לערוך את הפלייליסט ישירות בגיליון)
- **בקאנד:** Google Apps Script — קובץ אחד ([appscript.gs](appscript.gs))
- **פרונטאנד:** HTML/JS נקי, בלי שרת — מתאחסן בחינם ב-GitHub Pages
- **קבצים:**
  - `player.html` — הנגן. את הכתובת שלו מגדירים בדפדפן הקיוסק שעל המסך.
  - `index.html` — דף הניהול. את הכתובת שלו שומרים בנייד.
  - `appscript.gs` — הבקאנד. מודבק ב-Apps Script (לא עולה ל-GitHub בהכרח).

## התקנה חד-פעמית (כ-15 דקות)

### שלב 1 — יצירת הדאטהבייס (Google Sheet)

1. נכנסים אל https://sheets.google.com ויוצרים גיליון חדש ריק.
2. נותנים לו שם, למשל: `הקיוסק של 42 — DB`.
3. מתוך כתובת הגיליון `https://docs.google.com/spreadsheets/d/<SHEET_ID>/edit` מעתיקים את ה-**SHEET_ID** — המחרוזת הארוכה שבין `/d/` לבין `/edit`.

> הגיליונות עצמם (playlist, settings) נוצרים אוטומטית בקריאה הראשונה — אין צורך ליצור אותם ידנית.

### שלב 2 — הבקאנד (Apps Script)

1. בתוך הגיליון: **Extensions ← Apps Script**. נפתח עורך בטאב חדש.
2. מוחקים את ה-`function myFunction() {}` הריק.
3. מדביקים את כל התוכן של הקובץ [appscript.gs](appscript.gs).
4. בשורה למעלה מחליפים את `PASTE_YOUR_SHEET_ID_HERE` ב-SHEET_ID משלב 1.
5. שומרים (Ctrl+S).

### שלב 3 — פרסום כ-Web App

1. **Deploy ← New deployment**.
2. לוחצים על גלגל השיניים ← **Web app**.
3. מגדירים:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. **Deploy** ← מאשרים הרשאות (גוגל תזהיר על "unverified app" — לוחצים Advanced וממשיכים).
5. מעתיקים את כתובת ה-**Web app** שמסתיימת ב-`/exec`.

### שלב 4 — חיבור הפרונטאנד

בקובץ [config.js](config.js):
1. מדביקים את כתובת ה-`/exec` משלב 3 ב-`SCRIPT_URL`.
2. מדביקים את כתובת הגיליון המלאה ב-`SHEETS_URL`.

אפשר כבר עכשיו לפתוח את `index.html` מקומית בדפדפן ולוודא שהכול עובד.

### שלב 5 — העלאה לאינטרנט (GitHub Pages, בחינם)

1. מעלים את התיקייה לריפו ב-GitHub.
2. בריפו: **Settings ← Pages ← Source: main branch, / root ← Save**.
3. אחרי כדקה הכתובות יהיו:
   - ניהול: `https://<שם-משתמש>.github.io/<שם-ריפו>/`
   - נגן: `https://<שם-משתמש>.github.io/<שם-ריפו>/player.html`

### שלב 6 — הגדרת הסטרימר (המסך עצמו)

הדרך המומלצת על מכשיר אנדרואיד: אפליקציית **Fully Kiosk Browser** (חינמית לשימוש בסיסי, מחנות האפליקציות או מ-fully-kiosk.com):

1. מתקינים את Fully Kiosk Browser על הסטרימר.
2. ב-Settings ← **Start URL**: מדביקים את כתובת ה-`player.html` משלב 5.
3. הגדרות מומלצות:
   - **Web Content Settings ← Autoplay Videos: ✔** (חובה כדי שסרטונים יתנגנו לבד, כולל דרייב)
   - **Web Content Settings ← Enable Fullscreen Videos: ✔**
   - **Web Content Settings ← Media Autoplay / Autoplay Videos with Sound: ✔** (רק אם רוצים סאונד)
   - **Kiosk Mode / Universal Launcher ← Fullscreen Mode: ✔**
   - **Kiosk Mode ← Hide Status Bar: ✔** ו-**Hide Navigation Bar: ✔** (מסך מלא באמת, בלי שורות מערכת)
   - **Device Management ← Keep Screen On: ✔**
   - **Device Management ← Launch on Boot: ✔**
   - **Advanced Web Settings ← Enable JavaScript Alerts: ✘**
4. אם רוצים **סאונד** בסרטונים: ב-Fully Kiosk מסמנים גם `Autoplay Videos with Sound` (או Media Autoplay), ובדף הניהול מכבים את "השתקת סרטונים" בהגדרות.

> אין Fully Kiosk? כל דפדפן אנדרואיד שיודע מסך מלא יעבוד, אבל בלי חלק מהיתרונות (הפעלה אוטומטית אחרי חשמל, מניעת כיבוי מסך וכו').

## שימוש יומיומי

- נכנסים מהנייד לדף הניהול, מוסיפים פריט: **קודם בוחרים מה מוסיפים** (הודעה / שקופית / יוטיוב / אתר / תמונה / וידאו / קובץ מהמסך / דרייב) — ונפתח טופס עם השדות הרלוונטיים לאותו סוג בלבד. אם מדביקים כתובת שמתאימה לסוג אחר (למשל קישור יוטיוב בתוך "אתר"), הסוג מתעדכן אוטומטית.
- **↕️ שינוי סדר בגרירה:** גוררים פריט בידית ⠿ (עובד גם במגע מהנייד). חיצי ▲▼ נשארו למי שמעדיף.
- **⚡ הכל מגיב מיד:** כל פעולה (הוספה, עריכה, מחיקה, השבתה, גרירה) מתעדכנת ברשימה באופן מיידי, והשמירה לגיליון רצה ברקע — עם חיווי "שומר... / ✓ נשמר" בכותרת הפלייליסט. אם שמירה נכשלת, הרשימה חוזרת למצב האמיתי ומוצגת שגיאה.
- **משך תצוגה:** לאתרים ותמונות — כמה שניות להציג. **לסרטונים אין צורך להגדיר משך** — הם רצים לפי אורך הסרטון עצמו. (אפשר בכל זאת להגדיר מספר שניות כתקרה קשיחה, שימושי לשידור חי שאף פעם לא נגמר.)
- **🔁 כמה פעמים לרוץ:** לכל סרטון בוחרים פעם אחת (ברירת מחדל) / 2 / 3 / 5 / 10 / בלופ בלי סוף — ואז עוברים לפריט הבא. "בלי סוף" מתאים לסרטון יחיד שתמיד על המסך; שימו לב שאם יש עוד פריטים בפלייליסט, פריט "בלי סוף" יחסום אותם.
  **החזרה מבוצעת על ידי הנגן עצמו** (‏`loop` טבעי), ולא בקפיצה חזרה להתחלה בסוף כל סבב — כך אין מעבר דרך מסך הסיום של הנגן ואין באפרינג מחדש. היציאה לפריט הבא מתוזמנת לפי אורך הסרטון כפול מספר החזרות.
  **⚠ אבל ביוטיוב אין לופ חלק.** נמדד: `<video>` של קובץ אמיתי חוזר להתחלה בתוך ‏**~10 מילישניות** (בלי טעינה מחדש — אותם בייטים בבאפר), בזמן שנגן היוטיוב **טוען את הסרטון מחדש** בין סבב לסבב — ‏`UNSTARTED → BUFFERING → PLAYING`, בסביבות ‏**חצי שנייה** של קפיצה בכל חזרה. זו מגבלה של יוטיוב, לא של הקיוסק. **לסרטון שאמור לרוץ בלופ — שומרים אותו כקובץ על המסך** (💾 קובץ מהמסך), ואז החזרה חלקה לחלוטין. דף הניהול מזהיר על זה כשבוחרים חזרות לפריט יוטיוב.
- **🖐 מצב נגיעה — ללחוץ, להקליד ולגלול בתוך אתר על המסך:** **לחיצה ארוכה (‏0.7 שניות) בכל מקום על המסך**, ואז המסך מועבר לתוכן עצמו: לחיצות, הקלדה וגלילה מגיעות לאתר. **הסבב קופא** — הפלייליסט לא יחליף את מה שאתם באמצע, וגם עדכון מהניהול לא יזיז את התוכן. שימושי בדיוק למשהו כמו התחברות לחשבון באתר מוטמע.
  למה זה צריך מצב מיוחד: הקיוסק בנוי להיות **לא נגיע** — שכבת התוכן (`#stage`) לא מקבלת אירועי מצביע בכלל, ומעליה יש שכבת מחוות שהופכת נגיעה לסוויפ בפלייליסט. מצב נגיעה מבטל את שתיהן לזמן מוגבל.
  **יציאה:** כפתור `יציאה ✕` בפס שנפתח למטה, מקש `T` או `Esc`, וגם **אוטומטית אחרי 3 דקות** — בפס מוצג טיימר לאחור, כדי שמסך ציבורי לא יישאר פתוח לנגיעות. גם מעבר פריט מכל סיבה אחרת מסיים את המצב.
- **👉 סוויפ להחלפת פריט:** **גרירה שמאלה = הפריט הבא, גרירה ימינה = הפריט הקודם** — בכל מקום על המסך, גם כשמוצג אתר או סרטון, **וגם ממסך ההמתנה**. חץ קצר (‹‹ / ››) מהבהב כדי לאשר שהמחווה נקלטה. במקלדת: `←` הבא, `→` הקודם, רווח = הבא. מעבר יזום **מדלג על הפסקת ההמתנה** ומעלה את הפריט מיד כשהוא מוכן — אחרת סוויפ ממסך ההמתנה רק היה מאריך את ההמתנה בעוד 10 שניות, ונראה כאילו המחווה לא נקלטה.
  (במצב נגיעה הסוויפ מושבת — הנגיעות שייכות לאתר.)
- **🔓 מסך מלא / יציאה ממסך מלא: **דאבל-טאפ בכל מקום במסך**. אותה מחווה מכניסה ומוציאה (גם מקש `X` במקלדת). אחרי יציאה מכוונת הנגן לא מנסה להיכנס בחזרה לבד.
  **שימו לב שיש שתי שכבות:** זו יציאה ממסך מלא של הדף, אבל אם Fully Kiosk עצמו במצב קיוסק (בלי שורת מערכת) — יוצאים ממנו דרך Fully עצמו (ברירת המחדל שלו: הקשה מרובה בפינה או מחווה מהקצה, לפי ההגדרות שלו).
- **⚡ איכות וידאו ביוטיוב:** יוטיוב בוחר איכות לפי **גודל הנגן שהוא רואה**, לכן הנגן מודד את המסך ומבקש נגן בגודל האמיתי (עד 2560px), ובנוסף מבקש ממנו את הרזולוציה הגבוהה ביותר הזמינה. אם האיכות בכל זאת נמוכה — החשודים הם רוחב פס איטי במשרד או הסרטון עצמו שהועלה באיכות נמוכה.
- **🙈 התוכן נחשף רק כשהוא ממש זז:** הנגן לא מסיר את מסך ההמתנה ברגע שהוא *ביקש* מהסרטון להתחיל, אלא כשהסרטון **באמת מתנגן** (עד 2.5 שניות המתנה, ואז ממשיכים בכל מקרה). בלי זה נראתה לרגע תמונת הפוסטר של יוטיוב עם כפתור הפליי עליה — בדיוק מה שמסך ההמתנה קיים כדי להסתיר.
- **⏳ מסך המתנה בין פריטים (והטעינה קורה בדיוק אז):** בין פריט לפריט מוצג מסך ההמתנה (שעון + ההודעה שלכם) למשך **10 שניות כברירת מחדל**, ובזמן הזה הפריט הבא נטען ברקע. ניתן לשינוי בהגדרות ("מסך המתנה בין פריטים") — ‏0 = מעבר ישיר בלי הפסקה.
- **⏳ טעינה מראש:** בעוד פריט מוצג, הפריט הבא כבר נטען ברקע (סרטונים מקומיים וקבצי mp4 מתבצרים, תמונות נמשכות), כך שהמעבר קצר. בזמן שנשאר — מוצג מסך ההמתנה, לא מסך שחור.
- **📐 מסך אנכי / מסך מלא:** ברירת המחדל היא `מלא מסך` — התוכן ממלא את כל המסך (הקצוות נחתכים). בהגדרות אפשר להחליף ל-`שלם` (רואים את כל התמונה, עם פסים שחורים), וגם לקבוע לכל פריט בנפרד. אתרים לא מושפעים — הם מסתדרים לבד לרוחב המסך (ולרוב יציגו גרסת מובייל, שמתאימה מאוד למסך אנכי).
- **⏳ לוח ההמתנה:** מעוצב באותה שפה כמו ההודעות — לוח הבלון **הכתום**, עם השעה בגדול, התאריך בעברית ושורת הפרסום מתחת. כך כל מצב על המסך מזוהה בצבע: **כתום = המתנה, ורוד = הודעה, סגול = שקופית, והרובוט העצוב (ERROR) = פריט שנכשל.** לוח ההמתנה מוצג בכל רגע שבו תוכן עוד נטען, מתחלף או תקוע — התוכן נחשף רק כשהוא ממש מתחיל לרוץ, ופריט שלא הצליח להתחיל בתוך 7 שניות מדולג. כשל כזה (קישור שבור, קובץ חסר, וידאו שנתקע) מציג לרגע את לוח ה-ERROR המעוצב (`assets/error-pink.png`) עד שהפריט הבא עולה — כך תקלה נראית כתקלה, לא כהמתנה ארוכה. גם שורת הפרסום מתכווננת לאורך שלה, כמו בהודעות.
- **🔊 הודעת מסך ההמתנה:** נערכת בהגדרות ("הודעה במסך ההמתנה").
- **📢 הודעה למשרד / 📝 שקופית טקסט / 🤖 מסך ERROR:** סוגי פריטים שהמסך מצייר לבד — בלי כתובת ובלי קובץ. ממלאים טקסט, וזה הכל.
  **הכותרת על המסך היא שדה נפרד ואופציונלי** (`כותרת על המסך`): אם ממלאים אותו, הוא מופיע בגדול מעל הטקסט; אם משאירים ריק — מוצג רק הטקסט כמו שהוא. השדה `שם` הוא **לזיהוי הפריט בפלייליסט בלבד ולא מוצג על המסך אף פעם**.
  - **הודעה** — לוח "הודעה חשובה" הוורוד של הסטודיו.
  - **שקופית** — לוח הבלון הסגול.
  - **מסך ERROR** — אותו לוח רובוט שמוצג אוטומטית כשפריט נכשל, כאן כפריט מכוון (שימושי להודעות "המערכת בתחזוקה", בדיחות משרדיות וכו').
  שני הלוחות הם האמנות המקורית (`assets/*.png`, יחס 9:16 — בדיוק כמו המסך), והטקסט נכנס לתוך בלון הדיבור. מיקום הבלון נמדד מהקובץ עצמו, ולכן הטקסט יושב בו במדויק. גודל האותיות מותאם אוטומטית: מתחיל גדול ומצטמצם עד שהטקסט נכנס — הודעה של מילה אחת תהיה ענקית, פסקה שלמה תהיה קטנה יותר, ובשום מצב לא תיחתך.
  **פונט:** Assistant (חופשי, נטען מ-Google Fonts) — כך שהוא נראה זהה על המסך, בנייד ובמחשב.
  להחלפת עיצוב: `assets/notice-pink.png` / `assets/slide-purple.png` (קיים גם `slide-orange.png`), והמיקומים בבלוק `.bubble` ב-`player.html`.
  משך התצוגה של שניהם נקבע כמו לאתרים ותמונות (משך מוגדר, או ברירת המחדל).
- **📁 סרטונים מגוגל דרייב:** מדביקים את קישור השיתוף הרגיל (`https://drive.google.com/file/d/.../view`) — הסוג מזוהה אוטומטית. **הקובץ חייב להיות משותף כ"כל מי שיש לו הקישור"** (Anyone with the link), אחרת המסך יראה שגיאה.
- שינויים נקלטים במסך אוטומטית תוך עד דקה (אפשר לשנות בהגדרות).
- **🔄 רענון המסך** — מאלץ את הנגן לעשות reload מלא (שימושי אחרי עדכון גרסה). **המסך לא מתרענן מיד** — הוא לומד על זה בבדיקה הבאה שלו (עד 'בדיקת עדכונים' שניות, כברירת מחדל 60). הכפתור ממתין בפועל למסך ומאשר "המסך התרענן ✓" כשזה קרה באמת; אם לא — הוא יגיד שהמסך לא דיווח. רוצים תגובה מהירה יותר? להקטין את 'בדיקת עדכונים' בהגדרות (לא מתחת ל-30 שניות, כדי לא לחרוג ממגבלת זמן הריצה היומית של Apps Script).
- נקודת הסטטוס למעלה מראה אם המסך חי ומה הוא מציג עכשיו.
- **⚠ למה פריט לא עובד:** כשפריט נכשל על המסך, הנגן מדווח **מה נכשל ולמה**, ועמוד הניהול מציג את זה בשורה אדומה מתחת לסטטוס — למשל `הפורמט או הקודק של הקובץ לא נתמך בדפדפן הזה (נסו MP4/H.264)`, `הקובץ לא שמור על המסך הזה`, `לא הצליח להתחיל לרוץ תוך 7 שניות` או `יוטיוב סירב לנגן את הסרטון`. בנוסף, פריט מסוג `קובץ מהמסך` שמצביע על קובץ שלא נמצא על המסך מסומן ברשימה בתג `⚠ הקובץ לא על המסך`.

## חשוב לדעת

- **⚠ עדכון הבקאנד:** כל שינוי ב-`appscript.gs` מחייב פרסום מחדש! Deploy ← Manage deployments ← ✏ ← Version: **New version** ← Deploy. בלי זה הכתובת ממשיכה להריץ את הקוד הישן.
- **אתרים שדורשים התחברות:** אפשר להתחבר פעם אחת דרך **מצב נגיעה** (לחיצה ארוכה על המסך), והעוגייה נשמרת בדפדפן של המסך — כך שהפריט ימשיך להופיע מחובר גם אחרי החלפות פריט. שימו לב שזה אומר שהחשבון נשאר מחובר על מסך ציבורי.
- **אתרים שחוסמים הטמעה:** חלק מהאתרים (בנקים, גוגל, חלק מאתרי חדשות) לא מרשים להציג אותם בתוך iframe — הם יופיעו ריקים במסך. דף הניהול מריץ בדיקה אוטומטית בשמירה ומזהיר.
- **סרטוני יוטיוב:** מומלץ סרטונים רגילים או "לא רשומים" (Unlisted). לשידור חי מיוטיוב — להגדיר משך תצוגה, אחרת הוא יתחלף אחרי 30 דקות (מנגנון הבטיחות).
- **💾 קובץ ששמור על המסך עצמו (בלי אינטרנט, בלי מגבלת גודל):** **פותחים את עמוד הניהול מהמסך עצמו** (או מהמחשב שמריץ את המסך) ← ➕ הוספת פריט ← 💾 **קובץ מהמסך** ← `בחירת קבצים מהמכשיר הזה`. זה הכל: הקובץ נשמר בזיכרון של המכשיר ונוסף לפלייליסט (קובץ אחד נכנס לטופס כדי שאפשר יהיה לקבוע חזרות/התאמה; כמה קבצים ביחד נוספים ישר). מאותו רגע מנהלים אותו מהנייד כמו כל פריט.
  בתוך הטופס כתוב אם המכשיר שאתם עליו הוא באמת המסך (`✔ זה המכשיר של המסך`), ומופיעה רשימת הקבצים ששמורים עליו עם כפתור מחיקה — כך אפשר לפנות מקום בלי לגשת לנגן.
  **חשוב:** האחסון הוא **מקומי לדפדפן של המכשיר**, ולכן בחירת קובץ מהנייד לא תעשה כלום למסך. עמוד הניהול מזהיר על זה.
  זו הדרך הכי אמינה לסרטון: הוא מתנגן גם כשהאינטרנט נופל, בלי העלאות ובלי תקרת גודל מלבד הזיכרון של המכשיר.

- **🎬 לסרטונים מהענן: יוטיוב כ-Unlisted היא הדרך המומלצת.** מעלים את הסרטון ליוטיוב, בוחרים `Unlisted` (לא רשום — לא מופיע בחיפוש ולא בערוץ, רק מי שיש לו הקישור רואה), ומדביקים את הקישור בפאנל. זה מתנגן אוטומטית, בלופ, במסך מלא, בלי מגבלת גודל ובלי הגדרות שיתוף. אם התוכן רגיש — קחו בחשבון שכל מי שמכיר את הקישור יכול לצפות.

## מבנה הדאטה (למי שעורך ישירות בגיליון)

**גיליון `playlist`:** `id, title, type, url, duration, active, order, created, loop, fit, loops, text, heading`
- `type`: ‏`youtube` / `video` / `drive` / `local` / `website` / `image` / `slide` / `notice` / `error`
  (‏`local` = קובץ ששמור על המסך עצמו; העמודה `url` מכילה את שם הקובץ)
- `duration`: שניות. ‏0 = לפי אורך הסרטון (וידאו) או ברירת המחדל (אתר/תמונה)
- `active`: ‏`כן` / `לא`
- `order`: מספר — סדר התצוגה
- `loops`: כמה פעמים הסרטון רץ לפני הפריט הבא. ‏1 = פעם אחת, ‏0 = בלי סוף
- `loop`: ‏`כן`/`לא` — משקף רק אם `loops` הוא 0 (נשאר לקריאות בגיליון ולתאימות לאחור)
- `fit`: ריק (לפי ההגדרה הכללית) / `contain` / `cover`
- `text`: גוף הטקסט לשקופית/הודעה/ERROR (לסוגים האלה העמודה `url` נשארת ריקה)
- `heading`: כותרת אופציונלית שתוצג על המסך מעל הטקסט. ריק = רק הטקסט. `title` לא מוצג על המסך.

**גיליון `settings`:** `key, value` — נוצר אוטומטית עם ערכי ברירת מחדל.
