# videos/

קבצי וידאו שמתארחים יחד עם הנגן.

**למה כאן ולא בדרייב:** גוגל לא מרשה לדפדפן באתר אחר להזרים קובץ וידאו מדרייב,
ולכן סרטון מדרייב נופל לנגן המוטמע של דרייב — שלפעמים דורש לחיצה על פליי.
קובץ שיושב כאן מוגש ישירות על ידי GitHub Pages, ולכן מתנגן אוטומטית, בלופ ובמסך מלא.

## איך מוסיפים סרטון

1. מעלים לכאן קובץ mp4 (גם מהנייד: הריפו ב-GitHub ← התיקייה `videos` ← Add file ← Upload files).
2. בפאנל הניהול: הוספת פריט ← סוג "קובץ וידאו" ← כתובת:
   `https://orisamuel.github.io/kiosk-42/videos/<שם-הקובץ>.mp4`

## מגבלות

- עד 100MB לקובץ (מגבלת GitHub). לסרטון כבד יותר — יוטיוב כ-Unlisted.
- הריפו ציבורי: כל קובץ כאן נגיש לכל מי שמכיר את הכתובת.
- עדיף mp4 עם קודק H.264 — נתמך בכל דפדפן.
